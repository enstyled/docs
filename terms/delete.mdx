---
title: 'Delete term'
description: 'Delete a term that has no jobs'
api: 'DELETE /terms/{id}.json'
---

<Note>Requires admin authentication</Note>

Only terms without jobs can be deleted, and a board always keeps at least one term. To delete a term that still has jobs, first move them to another term with [Update job](/jobs/update) by setting `term_id`.

<ParamField path="id" type="integer" required>
  The id of the term to delete
</ParamField>

<ResponseExample>
```json 200
{
  "message": "Term was successfully deleted."
}
```

```json 422
{
  "base": [
    "It still has 2 jobs. Move them to another term first."
  ]
}
```
</ResponseExample>
